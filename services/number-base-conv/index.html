What a number base actually is

A base is simply how many distinct digits a system uses before it rolls over into another column. Decimal has ten, so after 9 comes 10. Binary has two, so after 1 comes 10 — which is the number two, not ten. Each column is worth the base raised to its position, counting from zero on the right, and that single rule generates every base from 2 to 36.

Binary matters because circuits are switches: on or off, one or zero. Hexadecimal matters because it is a compact way of writing binary — one hex digit maps to exactly four bits, so any byte becomes two readable characters. Octal survives mainly in Unix file permissions, where three bits per group maps neatly onto read, write and execute.

Worked example 1: binary to decimal

Take 1011. Positions from the right are worth 1, 2, 4 and 8. Reading right to left the digits are 1, 1, 0, 1, so the value is 1 + 2 + 0 + 8 = 11. In hex that is B, and in octal 13. All four appear at once in the results panel, which is the fastest way to sanity check a value you have half-converted in your head.

Worked example 2: hex to decimal, the colour case

CSS colours are hex bytes. The red channel in #FF8800 is FF, which is 15 x 16 + 15 = 255 — the maximum for one byte. The green channel 88 is 8 x 16 + 8 = 136. Knowing that FF is 255 and 80 is 128 makes it easy to judge whether a colour is near-saturated or roughly half strength without opening a picker.

Worked example 3: file permissions in octal

chmod 755 means three octal digits, each holding three bits: 7 is 111 (read, write, execute), 5 is 101 (read, execute). Convert 755 with base 8 selected and the binary output reads 111101101 — exactly the nine permission bits in order. This is why octal, not hex, is the traditional notation for Unix modes.

Practical notes and limits

This converter handles whole numbers up to 2^53, the largest integer JavaScript represents exactly. Beyond that, results would silently lose precision, so the tool refuses rather than printing a plausible wrong answer. Negative numbers are converted as magnitude with a minus sign, because two's complement representation depends on a chosen word width — an 8-bit and a 32-bit representation of -5 are different bit patterns, and guessing which one you meant would be worse than not guessing.

The digit check runs before conversion for the same reason. Typing 129 with base 8 selected is a mistake, not a value: standard parsing would quietly return 10 by stopping at the invalid 9. Flagging it keeps a typo from becoming a wrong number in your code.

Bases above 16 use letters through Z, giving base 36 as the practical maximum with the standard alphabet. Base 36 shows up in short identifiers and URL slugs precisely because it packs the most value per character while staying alphanumeric.

Frequently asked questions

How do I convert binary to decimal by hand?

Multiply each digit by two raised to its position, counting from zero on the right, and add. For 1011: 1x8 + 0x4 + 1x2 + 1x1 = 11. The converter does the same thing, which is useful when you want to check your own working rather than replace it.

Why does hexadecimal use letters?

Base 16 needs 16 distinct digits and we only have ten numerals, so A to F stand for 10 to 15. Hex is popular because one hex digit is exactly four bits, so a byte is always two hex characters — far easier to read than eight ones and zeros.

What does the bit count tell me?

It is the smallest number of binary digits that can hold the value, which tells you the smallest integer type that fits. A value needing 9 bits will not fit in an 8-bit byte, and one needing 33 bits overflows a 32-bit signed integer.
